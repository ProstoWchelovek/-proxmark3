**Профессиональное приложение для работы с Proxmark3 Easy с прошивкой Iceman**

## 📋 Описание

ProxMaster Ultimate - это современное desktop-приложение с графическим интерфейсом для работы с устройством Proxmark3 Easy (и совместимыми версиями с прошивкой Iceman). Приложение полностью заменяет работу с командной строкой, предоставляя удобный и интуитивно понятный интерфейс.

### ✨ Основные возможности

- **9 вкладок** для всех аспектов работы с устройством:
  - 🏠 ГЛАВНАЯ - базовые функции устройства
  - 🔍 ПОИСК - автоматическое определение карт LF/HF
  - 💾 МЕНЕДЖЕР ДАННЫХ - сохранение карт и ключей + Hex-редактор
  - ✏️ ЗАПИСЬ - запись данных на карты
  - 🎭 ЭМУЛЯЦИЯ - эмуляция различных типов карт
  - 📡 СНИФИНГ - перехват трафика
  - 📜 СКРИПТЫ - Lua и Node.js скрипты
  - 🛠️ ИНСТРУМЕНТЫ - графики, анализ, дополнительные инструменты
  - ⚙️ НАСТРОЙКИ - обновления и конфигурация

- **Встроенный Hex-редактор** для просмотра и редактирования дампов
- **Node Editor** для создания пользовательских скриптов и атак
- **ИИ-помощник** с поддержкой локальных моделей (LM Studio, Cherry Studio, Ollama)
- **Режим разработчика** для изменения кода в реальном времени
- **Система обновлений** приложения и прошивки устройства
- **Цветовой вывод логов** с прогресс-барами
- **Безопасный режим** с подтверждениями для опасных операций

## 🚀 Быстрый старт

### Требования

- Windows 10/11
- Python 3.8 или выше
- Установленная ProxSpace (опционально, для полной функциональности)
- Устройство Proxmark3 Easy с прошивкой Iceman

### Установка

1. **Скачайте репозиторий:**
   ```bash
   git clone https://github.com/yourusername/ProxMaster_Ultimate.git
   cd ProxMaster_Ultimate
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Запустите приложение:**
   - На Windows: запустите `run_app.bat`
   - Или через Python: `python proxmaster_ultimate.py`

### Автоматическая установка (Windows)

Просто запустите файл `run_app.bat` - он автоматически:
- Проверит наличие Python
- Создаст виртуальное окружение
- Установит все зависимости
- Запустит приложение

## 🎯 Использование

### Подключение устройства

1. Подключите Proxmark3 Easy к USB
2. В меню выберите "Устройство" → "Подключить"
3. Индикатор справа сверху покажет статус подключения

### Работа с командами

- Каждая кнопка выполняет соответствующую команду Proxmark3
- Значок **ℹ** - простая подсказка при наведении
- Значок **ⓘ** - клик показывает подробную информацию о команде
- Опасные операции требуют подтверждения

### Hex-редактор

Доступен во вкладке **"МЕНЕДЖЕР ДАННЫХ"**:
- Открытие файлов .bin, .eml
- Просмотр в hex и ASCII форматах
- Редактирование данных
- Сохранение изменений

### Node Editor

Доступен во вкладке **"СКРИПТЫ"**:
- Создание новых скриптов
- Редактирование существующих
- Запуск и отладка
- Шаблоны для быстрого старта

### ИИ-помощник

Нажмите кнопку **"🤖 ИИ-помощник"** в верхней панели:
- Выбор модели (local, LM Studio, Cherry Studio, Ollama)
- Режим разработчика для расширения возможностей
- Помощь в управлении устройством
- Генерация скриптов

## 🔧 Команды

Все команды хранятся в файле `commands.json` и могут быть легко изменены:

```json
{
  "id": "hw_status",
  "name": "Статус устройства",
  "command": "hw status",
  "description": "Получение полного статуса устройства...",
  "level": "!!",
  "category": "device",
  "safe": true
}
```

### Уровни команд

- **!** - Информативная команда, показывает справку при наведении
- **!!** - Команда с info, выполняет `info <command>` при клике на значок

## ⚙️ Настройки

Во вкладке **"НАСТРОЙКИ"** можно изменить:
- Путь к установке ProxSpace
- COM-порт для подключения
- Тему оформления (тёмная/светлая)
- Проверка обновлений

## 🔐 Безопасность

- Все опасные операции (запись, прошивка, форматирование) требуют подтверждения
- Рекомендуется создавать резервные копии дампов перед записью
- Приложение не выполняет операции без явного подтверждения пользователя
