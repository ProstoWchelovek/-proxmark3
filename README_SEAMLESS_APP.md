# 🚀 Proxmark3 Seamless Application

**Единое приложение для установки, прошивки и работы с Proxmark3 Iceman "из коробки"**

## 📋 Описание

Это приложение объединяет в себе:
- ✅ Автоматическую установку всех зависимостей
- ✅ Клонирование репозитория Proxmark3 Iceman
- ✅ Компиляцию клиента и прошивки
- ✅ Прошивку устройства
- ✅ Запуск оригинального клиента
- ✅ Запуск Russian GUI
- ✅ Консоль для быстрых команд

## 🎯 Возможности

### Вкладка "Установка"
- Проверка зависимостей (Python, Git, GCC, Make)
- Авто-установка зависимостей для Linux (Ubuntu/Debian/Fedora/Arch)
- Клонирование репозитория Proxmark3
- Компиляция прошивки и клиента
- Визуальный статус каждого компонента

### Вкладка "Прошивка"
- Поиск подключенных устройств Proxmark3
- Прошивка Bootrom
- Прошивка Fullimage
- Полная прошивка устройства
- Индикация прогресса

### Вкладка "Управление"
- Быстрые команды (hw status, hw tune, hf search, lf search, etc.)
- Консоль для ввода произвольных команд
- Запуск оригинального клиента pm3
- Запуск Russian GUI

### Вкладка "Лог"
- Подробное логирование всех операций
- Сохранение лога в файл
- Очистка лога

## 📦 Установка

### Требования
- Python 3.6+
- Tkinter (python3-tk)
- PySerial (`pip install pyserial`)

### Быстрый старт

```bash
# Перейдите в директорию приложения
cd /workspace

# Запустите скрипт установки
./run_seamless_app.sh
```

Или напрямую:

```bash
python3 proxmark3_seamless_app.py
```

## 🔧 Пошаговая инструкция

1. **Запустите приложение**
   ```bash
   ./run_seamless_app.sh
   ```

2. **Проверьте зависимости**
   - Нажмите "🔍 Проверить зависимости"
   - Убедитесь, что все компоненты отмечены ✅

3. **Установите зависимости (если нужно)**
   - Нажмите "📦 Авто-установка (Linux)"
   - Введите пароль sudo при запросе

4. **Клонируйте репозиторий**
   - Нажмите "📥 Клонировать репозиторий"
   - Дождитесь завершения (~200MB)

5. **Компилируйте прошивку**
   - Нажмите "🔨 Компилировать"
   - Процесс займет 5-15 минут

6. **Подключите устройство**
   - Подключите Proxmark3 по USB
   - Перейдите на вкладку "Прошивка"
   - Нажмите "🔍 Найти устройства"

7. **Прошейте устройство**
   - Нажмите "🔄 Полная прошивка"
   - Дождитесь завершения

8. **Начните работу**
   - Используйте вкладку "Управление"
   - Или запустите Russian GUI

## 🎮 Быстрые команды

Приложение поддерживает быстрые команды:
- `hw status` - Статус устройства
- `hw tune` - Настройка антенн
- `hf search` - Поиск HF карт
- `lf search` - Поиск LF карт
- `hf mf reader` - Чтение Mifare карт
- `data plot` - График данных

## ⚙️ Конфигурация

Путь к репозиторию: `~/proxmark3`
Путь к клиенту: `~/proxmark3/client/pm3`
Путь к прошивке: `~/proxmark3/armsrc/obj/fullimage.elf`

## 🐛 Решение проблем

### Ошибка: "Tkinter не установлен"
```bash
# Ubuntu/Debian
sudo apt-get install python3-tk

# Fedora
sudo dnf install python3-tkinter

# Arch
sudo pacman -S tk
```

### Ошибка: "PySerial не найден"
```bash
pip3 install pyserial --user
```

### Ошибка компиляции
Убедитесь, что установлены все зависимости:
```bash
sudo apt-get install git gcc make libreadline-dev libncurses5-dev \
     libbluetooth-dev libusb-1.0-0-dev qt5-default qtmultimedia5-dev \
     libssl-dev liblua5.3-dev libpython3-dev
```

### Устройство не найдено
- Проверьте подключение USB
- Убедитесь, что у вас есть права доступа:
  ```bash
  sudo usermod -aG dialout $USER
  # или
  sudo usermod -aG tty $USER
  ```
- Переподключите устройство
