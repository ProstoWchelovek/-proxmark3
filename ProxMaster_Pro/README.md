# ProxMaster Pro - Профессиональный инструмент для Proxmark3

## Описание
ProxMaster Pro - это полноценное GUI-приложение для управления Proxmark3 Easy/Iceman, которое полностью заменяет командную строку. Приложение предоставляет интуитивный интерфейс с графиками, Hex-редактором, визуальным редактором команд (Node Editor) и поддержкой всех 800+ команд Proxmark3.

## Особенности
- **Полный набор команд**: Все 800+ команд из Proxmark3 Iceman/Easy в структурированном JSON
- **Графический интерфейс**: 9 вкладок с полным функционалом без командной строки
- **Визуализация**: Графики сигналов, спектрограммы, демоделяция в реальном времени
- **Hex Editor**: Продвинутый редактор шестнадцатеричных данных с Undo/Redo
- **Node Editor**: Визуальное создание скриптов из команд с помощью нод
- **Автообновление**: Обновление прошивки, базы команд и интерфейса
- **Drag & Drop**: Перетаскивание файлов дампов, ключей и скриптов
- **Цветные логи**: 5 уровней важности с фильтрацией
- **Уровни риска**: Safe/Medium/High/Dangerous с подтверждениями
- **Темная тема**: Современный интерфейс на русском языке

## Структура проекта
```
ProxMaster_Pro/
├── main_app.py              # Точка входа
├── config.json              # Настройки приложения
├── requirements.txt         # Зависимости Python
├── run_app.bat             # Скрипт запуска для Windows
├── README.md               # Документация
├── core/
│   ├── __init__.py
│   ├── main.py             # Ядро: CommandManager, CommunicationLayer
│   ├── commands.py         # Загрузка и обработка команд из JSON
│   ├── plotter.py          # Графики и визуализация
│   └── updater.py          # Система обновлений
├── widgets/
│   ├── __init__.py
│   ├── editors.py          # Hex Editor + Node Editor
│   ├── plots.py            # Виджеты графиков
│   ├── logs.py             # Панель логов
│   └── tabs.py             # Вкладки интерфейса
├── data/
│   ├── commands_full.json  # Полная база команд (800+)
│   └── user_data/          # Дампы, ключи, логи пользователя
├── nodes/                  # Шаблоны графов для Node Editor
└── assets/                 # Иконки и ресурсы
```

## Установка
```bash
pip install -r requirements.txt
python main_app.py
```

## Зависимости
- PyQt6 / PySide6 - GUI фреймворк
- pyqtgraph - Графики и визуализация
- pyserial - Связь с Proxmark3
- numpy - Обработка данных
- scipy - DSP функции
- qtpy - Абстракция Qt
