# ProxMaster Pro v1.0.0

Профессиональный инструмент для управления Proxmark3 с графическим интерфейсом.

## 🚀 Возможности

### 9 Функциональных вкладок:
1. **🏠 Главная** - Быстрые безопасные операции (статус, версия, простые чтения)
2. **🔍 Поиск** - Универсальный поиск LF/HF карт по протоколам
3. **💾 Менеджер** - Управление дампами карт и ключей со встроенным Hex редактором
4. **✏️ Запись** - Запись и клонирование карт (T55xx, Mifare и др.)
5. **🎭 Эмуляция** - Эмуляция различных типов карт
6. **📡 Сниффинг** - Перехват трафика между ридером и картой
7. **📜 Скрипты** - Визуальный Node Editor для создания скриптов
8. **🛠️ Инструменты** - Графики, анализ сигналов, обработка данных
9. **⚙️ Настройки** - Конфигурация, обновления, Roadmap

### Ключевые особенности:
- ✅ **857+ команд** из прошивки Iceman в базе данных JSON
- ✅ **Hex редактор** с Undo/Redo, копированием/вставкой, загрузкой/сохранением
- ✅ **Node Editor** - визуальное программирование последовательностей команд
- ✅ **Темная тема** - профессиональный дизайн в стиле VS Code
- ✅ **Цветовая индикация риска** - безопасные/опасные команды
- ✅ **Система обновлений** - проверка обновлений приложения, ProxSpace и прошивки
- ✅ **Логи событий** - цветной вывод с временными метками

## 🔧 Архитектура

### Data-Driven подход
Все команды хранятся в `data/commands.json` и могут быть легко изменены без правки кода:

```json
{
  "id": "mf_dump",
  "name": "Дамп памяти Mifare",
  "template": "hf mf dump",
  "risk_level": "safe",
  "timeout": 60000,
  "tab": "main"
}
```

### Уровни риска команд:
- 🟢 **safe** - Безопасные операции (чтение, информация)
- 🟡 **medium** - Средний риск (атаки на ключи)
- 🟠 **high** - Высокий риск (RAW команды)
- 🔴 **dangerous** - Опасные операции (запись, изменение UID)

## 📝 Добавление новых команд

1. Откройте `data/commands.json`
2. Добавьте команду в соответствующую категорию:
```json
{
  "id": "my_command",
  "name": "Моя команда",
  "description": "Описание",
  "template": "hf mycmd {param}",
  "risk_level": "safe",
  "timeout": 5000,
  "parameters": [
    {
      "name": "param",
      "type": "hex",
      "required": true,
      "description": "Параметр"
    }
  ]
}
```
3. Укажите `tab`: `main`, `search`, `write`, `emulation`, `sniffing`, `tools`
