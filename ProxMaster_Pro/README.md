# 🚀 ProxMaster Pro - Профессиональный инструмент для Proxmark3

[![Version](https://img.shields.io/badge/version-3.0.0-blue.svg)](https://github.com)
[![License](https://img.shields.io/badge/license-GPL--3.0-green.svg)](https://www.gnu.org/licenses/gpl-3.0.html)
[![Python](https://img.shields.io/badge/python-3.8+-yellow.svg)](https://www.python.org/)

**ProxMaster Pro** — это мощное GUI-приложение для управления устройством Proxmark3 Easy/Iceman под Windows, которое полностью заменяет командную строку и предоставляет профессиональный интерфейс для работы с RFID/NFC технологиями.

## ✨ Возможности

### 🔹 Полный функционал Proxmark3
- **857 команд** во всех категориях (HF, LF, Mifare, iCLASS, EMV и др.)
- Поддержка всех протоколов: ISO 14443-A/B, ISO 15693, Mifare Classic/Ultralight
- Работа с низкочастотными картами (LF): EM4100, HID Prox, Indala, T55xx
- Взлом ключей Mifare Classic (nested, hardnested, darkside)

### 🔹 Встроенные редакторы
- **Hex Editor** — продвинутый шестнадцатеричный редактор с Undo/Redo, выделением, копированием
- **Node Editor** — визуальный редактор скриптов на основе нод для создания сложных сценариев

### 🔹 Графики и анализ
- Визуализация сигналов в реальном времени
- FFT анализ, фильтрация шумов
- Отображение модуляции и декодирование

### 🔹 Система обновлений
- **Автообновление приложения** — проверка и установка новых версий прямо из программы
- **Обновление ProxSpace** — интеграция со средой разработки Gator96100
- **Обновление прошивки Iceman** — загрузка актуальных версий с RfidResearchGroup

### 🔹 Удобный интерфейс
- 11 функциональных вкладок
- Темная тема для комфортной работы
- Цветные логи с 5 уровнями важности
- Drag & Drop для файлов
- Полностью на русском языке

## 📦 Установка

### Требования
- Windows 10/11
- Python 3.8 или выше
- Устройство Proxmark3 Easy/Iceman (опционально для тестирования интерфейса)

### Быстрый старт

1. **Клонируйте репозиторий:**
```bash
git clone https://github.com/YOUR_USERNAME/ProxMaster_Pro.git
cd ProxMaster_Pro
```

2. **Установите зависимости:**
```bash
pip install -r requirements.txt
```

3. **Запустите приложение:**
```bash
python main_app.py
```

Или используйте готовый скрипт для Windows:
```bash
run_app.bat
```

### Создание установщика

Для создания полноценного EXE-установщика:

```bash
python installer.py
```

Это создаст автономный установщик `ProxMaster_Pro_Setup.exe` со всеми зависимостями.

## 🔌 Подключение устройства

1. Подключите Proxmark3 к компьютеру через USB
2. В приложении нажмите **"🔌 Подключить"**
3. Выберите COM-порт из списка
4. Статус изменится на **"🟢 Устройство подключено"**

## 🛠️ Разработка

### Добавление новых команд

Откройте `data/commands.json` и добавьте команду по шаблону:

```json
{
  "id": "hf_new_command",
  "category": "hf",
  "name": "Новая команда",
  "description": "Описание команды",
  "template": "hf new {params}",
  "risk_level": "safe",
  "timeout": 5000,
  "parameters": [],
  "examples": ["hf new"],
  "tips": ["Подсказка"]
}
```

### Создание узлов для Node Editor

Шаблоны хранятся в `data/nodes/`. Каждый узел имеет:
- Входные параметры
- Выходные данные
- Тип операции
- Визуальное представление
