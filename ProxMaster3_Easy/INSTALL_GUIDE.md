# 📦 Руководство по установке ProxMaster3 Easy

## ⚡ Быстрый старт

### Для пользователей Windows:

1. **Скачайте проект** или склонируйте репозиторий
2. **Запустите от имени администратора**: `install.bat`
3. Дождитесь завершения установки (20-40 минут)
4. Приложение запустится автоматически

---

## 🔧 Что устанавливается?

Установщик автоматически загрузит и настроит:

| Компонент | Описание | Размер |
|-----------|----------|--------|
| **MSYS2** | Среда разработки для Windows | ~300 МБ |
| **ProxSpace** | Инструменты и компиляторы RRGroup | ~200 МБ |
| **Iceman Firmware** | Прошивка для Proxmark3 Easy | ~50 МБ |
| **Зависимости Python** | PyQt6, pyserial, requests | ~50 МБ |

**Общий размер**: ~5 ГБ на диске

---

## 🎯 Особенности установки для Proxmark3 Easy

### ✅ Гарантированная совместимость

Установщик **намеренно** компилирует прошивку ТОЛЬКО для:
- **Proxmark3 Easy**
- **Proxmark3 Easy Plus**

Это достигается за счет:
1. Использования флага `PLATFORM=PM3EASY` при компиляции
2. Специфичных настроек для чипа PM3 Easy
3. Исключения компонентов для других версий (RDV4, Demo)

### 🛡️ Безопасность

- Установка происходит в изолированную директорию: `C:\Program Files\ProxMaster3_Easy`
- Не конфликтует с другими версиями ProxSpace
- Не затрагивает системные файлы Windows
- Создает резервную копию конфигурации

## 📋 Пошаговая инструкция

### Шаг 1: Подготовка

1. Убедитесь, что у вас есть **права администратора**
2. Проверьте наличие **5 ГБ свободного места** на диске C:
3. Подключитесь к **стабильному интернету** (потребуется скачать ~1 ГБ)
4. Закройте другие программы (компиляция загружает процессор)

### Шаг 2: Запуск установщика

```bash
# Вариант A: Через проводник
1. Найдите файл install.bat
2. Нажмите ПРАВОЙ кнопкой мыши
3. Выберите "Запуск от имени администратора"

# Вариант B: Через командную строку
1. Откройте CMD от имени администратора
2. Перейдите в папку проекта
3. Выполните: install.bat
```

### Шаг 3: Ожидание установки

Установщик выполнит следующие этапы:

```
[1/4] Установка MSYS2 ............ ~5 минут
[2/4] Клонирование Iceman ......... ~2 минуты
[3/4] Компиляция прошивки ......... 15-30 минут ⏳
[4/4] Настройка окружения ......... ~1 минута
```

**Важно**: 
- Не закрывайте окно установщика!
- Если появится запрос о подтверждении GPG-ключа, нажмите `Y`
- Экран может мигать — это нормально

### Шаг 4: Первый запуск

После успешной установки:

1. Приложение запустится **автоматически**
2. На рабочем столе появится ярлык
3. В меню Пуск появится папка "ProxMaster3 Easy"

## 🔍 Проверка установки

### Способ 1: Через приложение

1. Откройте ProxMaster3 Easy
2. Перейдите на вкладку **"ГЛАВНАЯ"**
3. Нажмите **"Поиск устройства"**
4. Должно отобразиться: `Proxmark3 Easy detected`

### Способ 2: Через терминал

1. Запустите: `C:\Program Files\ProxMaster3_Easy\ProxSpace_Shell.bat`
2. В терминале выполните: `cd proxmark3/client`
3. Запустите: `./proxmark3.exe`
4. Должна появиться консоль клиента

### Способ 3: Проверка версии

В терминале ProxSpace выполните:
```bash
cd proxmark3
git log -1
```
Должна отобразиться последняя версия Iceman firmware.

## ❌ Устранение проблем

### Ошибка: "Недостаточно прав администратора"

**Решение**: Запустите `install.bat` правой кнопкой → "Запуск от имени администратора"

### Ошибка: "Недостаточно места на диске"

**Решение**: 
1. Освободите минимум 5 ГБ на диске C:
2. Или измените путь установки в файле `installers/auto_installer.py`:
   ```python
   INSTALL_DIR = Path('D:\\ProxMaster3_Easy')
   ```

### Ошибка: "Не удалось скачать MSYS2"

**Причины**:
- Проблемы с интернетом
- Блокировка фаерволом
- Временная недоступность GitHub

**Решение**:
1. Проверьте подключение к интернету
2. Отключите антивирус/фаервол на время установки
3. Попробуйте позже

### Ошибка: "Компиляция не удалась"

**Возможные причины**:
- Нехватка оперативной памяти (нужно минимум 4 ГБ)
- Конфликт с антивирусом
- Поврежденные пакеты MSYS2

**Решение**:
1. Перезагрузите компьютер
2. Отключите антивирус
3. Запустите установку заново
4. Если ошибка повторяется, проверьте `install_log.txt`

### Ошибка: "Устройство не найдено"

**Причины**:
- Драйверы не установлены
- Устройство не подключено
- Неверный COM-порт

**Решение**:
1. Подключите Proxmark3 Easy к USB
2. Установите драйверы (должны установиться автоматически Windows 10/11)
3. В приложении выберите правильный COM-порт
4. Проверьте в Диспетчере устройств (COM-порты)

## 🔄 Обновление

### Автоматическое обновление

1. Откройте ProxMaster3 Easy
2. Перейдите на вкладку **"НАСТРОЙКИ"**
3. Нажмите **"Проверить обновления"**
4. Следуйте инструкциям

### Ручное обновление прошивки

```bash
# В терминале ProxSpace
cd proxmark3
git pull
make clean
make -j$(nproc)
make flash
```

### Обновление приложения

1. Скачайте новую версию проекта
2. Запустите `install.bat`
3. Установщик обнаружит существующую установку и обновит компоненты

---

## 🗑️ Удаление

### Полное удаление

1. Закройте ProxMaster3 Easy
2. Запустите **Панель управления** → **Программы и компоненты**
3. Найдите "MSYS2" и удалите
4. Удалите папку: `C:\Program Files\ProxMaster3_Easy`
5. Удалите ярлыки с рабочего стола

### Чистое удаление (рекомендуется)

```bash
# В командной строке от администратора
rmdir /s /q "C:\Program Files\ProxMaster3_Easy"
rmdir /s /q "C:\msys64"
```
