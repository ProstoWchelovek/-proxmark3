## 📖 Описание

**ProxMaster3 Easy** - профессиональное приложение для Windows для работы с устройством **Proxmark3 Easy** с прошивкой **Iceman**, установленной через **ProxSpace**.

Приложение предоставляет графический интерфейс для всех команд Proxmark3 Iceman firmware, включая:
- Поиск и чтение карт (LF/HF)
- Запись на карты
- Эмуляцию различных типов карт
- Снифинг трафика
- Работу со скриптами (Lua/Node.js)
- Встроенный Hex-редактор
- AI-помощник для помощи в управлении

## 🚀 Установка

### Быстрый старт:

1. Скачайте проект
2. Запустите `install.bat`
3. Следуйте инструкциям меню

### Ручная установка:

```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск приложения
python proxmaster_main.py
```

### Установка ProxSpace и Iceman:

Через меню приложения или вручную:

```bash
python installer/proxspace_installer.py
```

## 🎯 Использование

### Подключение к устройству:

1. Подключите Proxmark3 Easy к USB
2. Запустите приложение
3. Выберите COM-порт (автоопределение доступно)
4. Нажмите "🔗 Подключить"

### Основные операции:

#### Поиск карт:
- Перейдите во вкладку "🔍 Поиск"
- Выберите тип поиска (LF или HF)
- Нажмите нужную команду

#### Работа с дампами:
- Откройте "💾 Менеджер данных"
- Используйте Hex-редактор для просмотра/редактирования
- Сохраняйте дампы в папку `dumps/`

#### Создание скриптов:
- Откройте "📜 Скрипты"
- Напишите скрипт в Node Editor
- Сохраните и выполните

#### Обновление прошивки:
- Перейдите в "⚙️ Настройки"
- Нажмите "🔄 Обновить ProxSpace"
- Или "📥 Установить ProxSpace и Iceman"

## 📚 Команды

Все команды Proxmark3 Iceman firmware доступны через JSON файл `commands.json`:

- **850+ команд** во всех категориях
- Категории: LF, HF, WRITE, EMULATION, SNIFFING, SCRIPTS, TOOLS, SETTINGS
- Каждая команда имеет описание, иконку и предупреждения (если есть)

### Пример структуры команды:

```json
{
  "id": "lf_search_em410x",
  "name": "Поиск EM410x",
  "command": "lf search em410x",
  "description": "Поиск и чтение карт формата EM410x",
  "category": "LF",
  "icon": "🔍",
  "parameters": [],
  "warning": null
}
```

Приложение автоматически проверяет обновления:

1. При запуске
2. Через меню "Настройки"
3. Предлагает установить новую версию

### Обновление ProxSpace/Iceman:

```bash
# Через GUI
Настройки → Обновить ProxSpace

# Через CLI
python installer/proxspace_installer.py
```

## 🛠️ Решение проблем

### Устройство не найдено:
- Проверьте подключение USB
- Установите драйверы Proxmark3
- Попробуйте другой COM-порт

### Ошибка сборки прошивки:
- Убедитесь, что Git установлен
- Проверьте наличие места на диске (~2GB)
- Запустите от имени администратора

### PyQt6 не устанавливается:
```bash
pip install --upgrade pip
pip install PyQt6 --force-reinstall
```
