# 🤖 Интеграция ИИ Помощника в ProxMaster3 Easy

## Обзор

ProxMaster3 Easy включает полноценную интеграцию с локальными ИИ моделями для помощи в:
- Управлении устройством Proxmark3 Easy
- Редактировании данных карт (hex-дампы)
- Создании скриптов атак (Lua, Node.js)
- Адаптации приложения под пользователя
- Создании обновлений программы
- Режиме разработчика с live-editing кода

## Поддерживаемые провайдеры

### 1. LM Studio
- **Порт по умолчанию:** 1234
- **API:** OpenAI-compatible
- **Сайт:** https://lmstudio.ai/
- **Модели:** Любые GGUF модели (Llama, Mistral, Phi и др.)

### 2. Cherry Studio
- **Порт по умолчанию:** 1234
- **API:** OpenAI-compatible
- **Сайт:** https://cherry-ai.com/

### 3. Ollama
- **Порт по умолчанию:** 11434
- **API:** Собственный
- **Сайт:** https://ollama.ai/
- **Модели:** Llama, Mistral, Gemma, Phi и др.

## Установка

### Шаг 1: Установка зависимостей Python
```bash
cd /workspace/ProxMaster3_Easy
pip install -r requirements.txt
```

### Шаг 2: Установка ИИ сервера (на выбор)

#### Вариант A: LM Studio (Windows/Mac)
1. Скачайте с https://lmstudio.ai/
2. Установите и запустите
3. Загрузите модель (например, Llama-3.1-8B-Instruct)
4. Нажмите "Start Server" на порту 1234

#### Вариант B: Ollama (Windows/Mac/Linux)
```bash
# Windows/Mac: скачайте с https://ollama.ai/
# Linux:
curl -fsSL https://ollama.ai/install.sh | sh

# Загрузите модель
ollama pull llama3.1:8b-instruct

# Сервер запустится автоматически на порту 11434
```

#### Вариант C: Cherry Studio
1. Скачайте с https://cherry-ai.com/
2. Установите и запустите
3. Настройте модель в интерфейсе

### Шаг 3: Настройка в приложении

1. Запустите ProxMaster3 Easy
2. Откройте меню "Инструменты" → "AI Помощник" или нажмите кнопку "🤖" на панели
3. В плавающей панели выберите:
   - Провайдер (LM Studio / Cherry Studio / Ollama)
   - Модель из выпадающего списка
   - При необходимости настройте через ⚙️

## Режимы работы ИИ

### 1. General (Общий)
**Назначение:** Помощь в управлении устройством, объяснение команд

**Примеры запросов:**
- "Как прочитать карту Mifare Classic?"
- "Что делает команда hf mf autodump?"
- "Какие меры безопасности при работе с T55xx?"

### 2. Scripting (Скрипты)
**Назначение:** Создание и отладка скриптов Lua/Node.js

**Примеры запросов:**
- "Напиши скрипт для перебора ключей Mifare"
- "Как оптимизировать этот Lua скрипт?"
- "Создай Node.js скрипт для анализа дампа"

### 3. Hex Editor (Редактор дампов)
**Назначение:** Анализ и редактирование hex-дампов карт

**Примеры запросов:**
- "Объясни структуру этого дампа Mifare"
- "Где находятся ключи доступа в этом дампе?"
- "Как изменить UID в дампе EM410x?"

### 4. Developer (Разработчик) 🔓
**Назначение:** Полный доступ к коду приложения, создание обновлений

**Активация:** 
- Меню "Инструменты" → "Режим разработчика"
- Или через настройки ИИ (галочка "Режим разработчика")

**Возможности:**
- Анализ исходного кода ProxMaster3
- Предложения по улучшению архитектуры
- Написание новых функций и модулей
- Исправление багов в реальном времени
- Создание обновлений под новые версии ProxSpace/Iceman
- Генерация документации

**Примеры запросов:**
- "Добавь поддержку нового протокола в поиск"
- "Оптимизируй работу с COM-портом"
- "Создай модуль для работы с новым типом карт"
- "Обнови команды для последней версии Iceman"

### 5. Updates (Обновления)
**Назначение:** Анализ изменений в ProxSpace/Iceman, создание патчей

**Примеры запросов:**
- "Какие новые команды появились в Iceman v4.20000?"
- "Адаптируй приложение под изменения ProxSpace"
- "Создай changelog для новой версии"

## Конфигурация

Файл конфигурации: `models/ai_config.json`

```json
{
  "provider": "lm_studio",
  "host": "localhost",
  "port": 1234,
  "model": "",
  "timeout": 60,
  "max_tokens": 2048,
  "temperature": 0.7,
  "enabled": true,
  "dev_mode": false
}
```

### Параметры:
- **provider:** Провайдер (lm_studio, cherry_studio, ollama)
- **host:** Адрес сервера (по умолчанию localhost)
- **port:** Порт сервера
- **model:** Название модели (оставьте пустым для автоопределения)
- **timeout:** Таймаут запроса в секундах
- **max_tokens:** Максимальное количество токенов в ответе
- **temperature:** Креативность ответа (0.0-2.0, где 0 - детерминированный)
- **enabled:** Включить/выключить ИИ
- **dev_mode:** Режим разработчика

## API ИИ Помощника

### Базовое использование

```python
from core.ai_assistant import AIAssistant, AIProvider

# Создание экземпляра
ai = AIAssistant()

# Установка провайдера
ai.set_provider(AIProvider.OLLAMA, host="localhost", port=11434)

# Выбор модели
ai.set_model("llama3.1:8b-instruct")

# Запрос ответа
answer = ai.ask("Как прочитать карту EM410x?", mode="general")
print(answer)

# Потоковый ответ с колбэком
def on_chunk(chunk):
    print(chunk, end="", flush=True)

ai.add_callback(on_chunk)
ai.ask("Напиши скрипт для...", mode="scripting", stream=True)
ai.remove_callback(on_chunk)
```

### Режимы работы

```python
# Общий режим
ai.set_system_prompt("general")
ai.ask("Как работать с Proxmark3?")

# Режим скриптов
ai.set_system_prompt("scripting")
ai.ask("Создай Lua скрипт для...")

# Режим hex редактора
ai.set_system_prompt("hex_editor")
ai.ask("Объясни структуру дампа...")

# Режим разработчика
ai.enable_dev_mode(True)
ai.ask("Добавь новую функцию в...")

# Режим обновлений
ai.set_system_prompt("updates")
ai.ask("Что нового в Iceman v4.20000?")
```

### Управление историей

```python
# Очистить историю
ai.clear_history()

# Экспорт в файл
ai.export_conversation("conversation.json")

# Импорт из файла
ai.import_conversation("conversation.json")
```

### Статус и тестирование

```python
# Получить статус
status = ai.get_status()
print(status)
# {'enabled': True, 'provider': 'lm_studio', 'connected': True, ...}

# Проверить подключение
if ai.test_connection():
    print("ИИ доступен")
else:
    print("Нет подключения к ИИ серверу")
```

## Плавающая панель ИИ

### Элементы управления:

1. **Выбор провайдера:** LM Studio / Cherry Studio / Ollama
2. **Выбор модели:** Выпадающий список доступных моделей
3. **Индикатор статуса:** ● Зеленый (подключено) / ● Красный (не подключено)
4. **Область ответов:** Отображение диалога с ИИ
5. **Выбор режима:** general/scripting/hex_editor/developer/updates
6. **Кнопка очистки:** 🗑️ Очистить историю разговора
7. **Поле ввода:** Ввод вопросов
8. **Кнопка отправки:** Отправить ➤

### Кнопки заголовка:
- **⚙️ Настройки:** Конфигурация подключения
- **➖ Свернуть:** Минимизировать панель
- **❌ Закрыть:** Скрыть панель (не закрывая приложение)

### Перетаскивание:
Панель можно перетаскивать за заголовок в любое место экрана.

### Поверх окон:
Панель всегда поверх основного приложения (WindowStaysOnTopHint).

## Примеры использования

### Пример 1: Помощь в чтении карты

**Запрос:**
```
Как прочитать карту Mifare Classic 1K?
```

**Ответ ИИ (режим general):**
```
Для чтения Mifare Classic 1K выполните следующие шаги:

1. Положите карту на антенну Proxmark3
2. Выполните команду поиска:
   hf search
   
3. Если карта найдена, используйте autodump:
   hf mf autodump
   
4. Или ручной дамп с известным ключом:
   hf mf dump --key AFFFFFFFFFFFFF
   
5. Сохраните дамп:
   data save --f my_card_dump.eml
```

### Пример 2: Создание скрипта

**Запрос:**
```
Напиши Lua скрипт для проверки стандартных ключей Mifare
```

**Ответ ИИ (режим scripting):**
```lua
-- check_default_keys.lua
local TIMEOUT = 1000
local KEYS = {
    "FFFFFFFFFFFF",
    "000000000000",
    "A0A1A2A3A4A5",
    "D3F7D3F7D3F7",
    "04B3B0FA956B"
}

print("Проверка стандартных ключей Mifare...")

for sector = 0, 15 do
    for keytype = 0, 1 do
        for _, key in ipairs(KEYS) do
            local result = core.mifarecmd.apdu_exchange(
                tonumber(sector),
                keytype,
                key
            )
            
            if result.success then
                print(string.format(
                    "✅ Сектор %d, Ключ %s: %s",
                    sector,
                    keytype == 0 and "A" or "B",
                    key
                ))
                break
            end
        end
    end
end

print("Проверка завершена")
```

### Пример 3: Анализ дампа

**Запрос:**
```
Объясни структуру этого дампа Mifare:
00045E2A1C80
```

**Ответ ИИ (режим hex_editor):**
```
Это UID карты Mifare Classic:

Байты 0-3: 00 04 5E 2A - Уникальный идентификатор (UID)
Байт 4: 1C - Контрольная сумма (BCC)
Байт 5: 80 - Байт размера (SAK, указывает на 1K память)

Формат:
- UID: 4 байта (32 бита)
- BCC: XOR всех байтов UID
- SAK: Select Acknowledge

Производитель: NXP Semiconductors
Тип: Mifare Classic 1K (MF1S50)
```

### Пример 4: Режим разработчика

**Запрос:**
```
Добавь функцию для быстрого сохранения дампа в менеджер данных
```

**Ответ ИИ (режим developer):**
```python
# Добавить в gui/tabs/data_manager_tab.py

def quick_save_dump(self, data: bytes, prefix: str = "dump"):
    """Быстрое сохранение дампа с авто-именем"""
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    filename = f"{prefix}_{timestamp}.bin"
    
    filepath = os.path.join("dumps", filename)
    
    try:
        with open(filepath, 'wb') as f:
            f.write(data)
        
        self.log_signal.emit(f"💾 Дамп сохранен: {filename}", "SUCCESS")
        self.refresh_dump_list()
        
        return filepath
    except Exception as e:
        self.log_signal.emit(f"❌ Ошибка сохранения: {e}", "ERROR")
        return None
```

## Советы по использованию

### 1. Выбор модели
- **Для общих задач:** Llama-3.1-8B-Instruct, Mistral-7B
- **Для кода:** CodeLlama, DeepSeek-Coder, StarCoder
- **Для анализа:** GPT-4 (через LM Studio), Claude (через Cherry Studio)

### 2. Оптимизация производительности
- Используйте меньшие модели (7B-8B) для быстрых ответов
- Увеличьте max_tokens для сложных задач
- Настройте temperature (0.3 для точности, 0.7 для креативности)

### 3. Безопасность
- Не отправляйте конфиденциальные данные
- Проверяйте сгенерированный код перед запуском
- Используйте режим разработчика только при доверии

### 4. Режим разработчика
⚠️ **Внимание:** Режим разработчика дает ИИ доступ к коду приложения. Используйте только с доверенными моделями и в безопасной среде.

## Устранение проблем

### Проблема: Не подключается к ИИ
**Решение:**
1. Проверьте, запущен ли сервер (LM Studio/Ollama)
2. Убедитесь, что порт указан правильно
3. Проверьте брандмауэр Windows
4. Попробуйте http://127.0.0.1 вместо localhost

### Проблема: Пустой список моделей
**Решение:**
1. Загрузите модель в LM Studio/Ollama
2. Перезапустите сервер
3. Нажмите кнопку обновления в приложении

### Проблема: Медленные ответы
**Решение:**
1. Используйте меньшую модель (7B вместо 70B)
2. Уменьшите max_tokens
3. Запустите на GPU если возможно
4. Закройте другие приложения

### Проблема: Некорректные ответы
**Решение:**
1. Смените режим (general/scripting/developer)
2. Уточните вопрос
3. Попробуйте другую модель
4. Настройте temperature (меньше = точнее)
