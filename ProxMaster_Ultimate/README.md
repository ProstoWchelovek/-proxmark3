# ProxMaster Ultimate

Полноценное GUI приложение для управления Proxmark3 Easy/Iceman/RDV4 под Windows.

## 🚀 Возможности

### Основной функционал
- **Полная поддержка команд Proxmark3** - все команды через удобный интерфейс
- **9 функциональных вкладок** для различных операций
- **Автоматическая установка ProxSpace** (в разработке)
- **Цветные логи** с уровнями важности
- **Прогресс-бары** для длительных операций

### Уникальные особенности
- **Встроенный Hex редактор** для просмотра и редактирования бинарных данных
- **Визуальный Node Editor** для создания сложных скриптов из команд
- **Система обновлений** прошивки, приложения и базы команд
- **Drag & Drop** для файлов дампов
- **Русский интерфейс** полностью локализован

### Безопасность
- **Уровни риска операций** (Safe/Medium/High/Dangerous)
- **Подтверждение опасных операций**
- **Валидация параметров** перед выполнением
- **Отмена/Повтор действий** в hex редакторе

## 🛠️ Установка

### Требования
- Python 3.8+
- Windows 10/11
- Устройство Proxmark3 (Easy/Iceman/RDV4)
- Установленные драйверы Proxmark3

### Зависимости

```bash
pip install pyserial
pip install tkinter
```

### Запуск

```bash
python main_app.py
```

Или используйте `run_app.bat` для Windows.

## 📖 Использование

### Подключение устройства
1. Подключите Proxmark3 к USB порту
2. Нажмите кнопку "🔌 Подключить" в приложении
3. Дождитесь определения устройства

### Выполнение команд
1. Выберите категорию команд в дереве слева
2. Выберите нужную команду
3. Настройте параметры (если требуются)
4. Нажмите "▶ Выполнить команду"

### Работа с Hex редактором
- Откройте вкладку "🔢 Hex редактор"
- Загрузите дамп через Ctrl+O или меню Файл
- Редактируйте данные мышью или клавиатурой
- Сохраните изменения через Ctrl+S

### Создание скриптов в Node Editor
1. Перейдите на вкладку "🔗 Node Editor"
2. Добавьте узлы через правый клик или кнопку "+ Добавить узел"
3. Соедините узлы перетаскиванием от выходного порта к входному
4. Настройте параметры каждого узла
5. Сохраните граф и выполните кнопкой "▶ Выполнить"

## 📋 Категории команд

| Категория | Описание | Цвет |
|-----------|----------|------|
| 🔍 Поиск карт | Поиск HF/LF карт | Зеленый |
| 📖 Чтение данных | Чтение различных типов карт | Синий |
| 💳 Mifare операции | Атаки, дампы, ключи | Оранжевый |
| ✏️ Запись данных | Запись в перезаписываемые карты | Красный |
| 🎭 Эмуляция | Эмуляция карт с заданными параметрами | Фиолетовый |
| 👁️ Сниффинг | Перехват трафика | Голубой |
| 📊 Анализ | Анализ сигналов и данных | Коричневый |
| ⚙️ Устройство | Информация и настройки PM3 | Серый |

## ⚠️ Уровни риска

- **🟢 Safe** - Безопасные операции чтения
- **🟡 Medium** - Операции с умеренным риском
- **🟠 High** - Атаки и сложные операции
- **🔴 Dangerous** - Необратимая запись данных

## 🔧 Конфигурация

Файл `config.json` позволяет настроить:
- Тип подключения (USB/Bluetooth/WiFi)
- Таймауты и попытки переподключения
- Язык интерфейса
- Темную/светлую тему
- Канал обновлений (stable/beta/dev)

## 📝 Формат команд (commands.json)

Команды описываются в JSON формате:

```json
{
    "id": "hf_search",
    "category": "search",
    "name": "Поиск HF карт",
    "description": "Поиск и чтение всех высокочастотных карт",
    "command_template": "hf search",
    "risk_level": "safe",
    "timeout": 30,
    "parameters": [],
    "help_text": "Сканирует область на наличие HF карт"
}
```
