# ProxMaster Ultimate - Требования

## Основные зависимости

### Обязательные
```
tkinter>=8.6        # GUI фреймворк (встроен в Python)
pyserial>=3.5       # Последовательная связь с устройством
```

### Опциональные (для расширенной функциональности)
```
numpy>=1.20         # Для анализа сигналов и графиков
matplotlib>=3.4     # Визуализация графиков антенны
Pillow>=8.0         # Работа с изображениями
requests>=2.25      # Проверка обновлений онлайн
```

## Установка зависимостей

### Быстрая установка
```bash
pip install -r requirements.txt
```

### Ручная установка
```bash
pip install pyserial
pip install numpy
pip install matplotlib
pip install Pillow
pip install requests
```

## Системные требования

### Минимальные
- ОС: Windows 10 (64-bit)
- Процессор: Intel Core i3 или аналог
- ОЗУ: 4 GB
- Место на диске: 500 MB
- Python: 3.8+

### Рекомендуемые
- ОС: Windows 10/11 (64-bit)
- Процессор: Intel Core i5 или аналог
- ОЗУ: 8 GB
- Место на диске: 1 GB
- Python: 3.10+

## Драйверы устройства

### Для Proxmark3 Easy
- CP210x USB to UART Bridge Driver
- Или CH340 Driver (для китайских клонов)

### Для Proxmark3 Iceman/RDV4
- Стандартные драйверы Windows
- LibUSB может потребоваться для некоторых режиммов

## Проверка установки

```bash
# Проверка Python
python --version

# Проверка установленных пакетов
pip list | findstr "pyserial numpy matplotlib"

# Тестовый запуск без устройства
python main_app.py
```

## Устранение проблем

### Ошибка "No module named 'serial'"
```bash
pip install pyserial
```

### Ошибка "tkinter not found"
```bash
# Windows: переустановите Python с опцией tcl/tk
# Linux: sudo apt-get install python3-tk
# macOS: brew install python-tk
```

### Ошибка доступа к COM порту
- Запустите от имени администратора
- Проверьте права доступа к порту в Диспетчере устройств
