# Proxmark3 Easy GUI

Приложение для удобной работы с устройством Proxmark3 Iceman на Windows.

## Возможности

- **9 вкладок интерфейса**: Главная, Поиск и Чтение, Память и Ключи, Запись, Сниффинг, Эмуляция, Инструменты, Скрипты, Система
- **Автоматическая установка ProxSpace** при первом запуске
- **Цветной вывод консоли** с подсветкой статусов ([=], [+], [-], [!], [?])
- **Встроенные графики сигналов** (Matplotlib)
- **Hex-редактор памяти** для просмотра и редактирования дампов
- **Управление ключами Mifare**
- **Прошивка устройства** через GUI
- **Запуск Lua-скриптов**
- **Предупреждения** для опасных операций

## Требования

- Windows 10/11
- Python 3.10 или выше
- Устройство Proxmark3 (опционально, для работы с железом)

## Установка

1. Установите Python 3.10+ с [python.org](https://www.python.org/)
2. Скачайте файлы проекта в одну папку
3. Откройте командную строку в папке проекта
4. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Запуск

Дважды кликните на `run_app.bat` или выполните в командной строке:
```bash
python proxmark3_easy_gui.py
```

## Структура вкладок

1. **ГЛАВНАЯ** - Статус подключения, информация об устройстве, быстрые действия
2. **ПОИСК И ЧТЕНИЕ** - Auto-detect, поиск и чтение LF/HF карт, графики сигналов
3. **ПАМЯТЬ И КЛЮЧИ** - Hex-редактор, управление дампами и ключами
4. **ЗАПИСЬ** - Запись на карты, клонирование T5577, Magic UID
5. **СНИФФИNG** - Перехват трафика, сохранение дампов
6. **ЭМУЛЯЦИЯ** - Эмуляция карт из слотов или файлов
7. **ИНСТРУМЕНТЫ** - Детальный анализ сигналов, декодирование (ASK, FSK)
8. **СКРИПТЫ** - Запуск Lua-скриптов с аргументами
9. **СИСТЕМА** - Мастер установки ProxSpace, обновление прошивки, настройки

## Примечания

- При первом запуске приложение проверит наличие ProxSpace и предложит его установить
- Для работы с устройством необходимо подключить Proxmark3 по USB
- Все опасные операции (прошивка, запись) требуют подтверждения
- Логи работы можно сохранить через меню "Файл" → "Сохранить лог"
