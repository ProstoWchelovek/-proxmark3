# Proxmark3 Easy GUI

Полноценное Windows-приложение для работы с Proxmark3 Easy/Iceman с графическим интерфейсом.

## Особенности

- **9 вкладок интерфейса**: Главная, Поиск и Чтение, Память и Ключи, Запись, Сниффинг, Эмуляция, Инструменты, Скрипты, Система
- **Автоматическая установка ProxSpace**: Мастер установки при первом запуске
- **Цветной вывод консоли**: Подсветка статусов ([+], [-], [!], [=])
- **Прогресс-бары**: Визуализация выполнения длительных операций
- **Безопасность**: Предупреждения перед опасными операциями
- **Автономность**: Работает без командной строки

## Структура проекта

```
/workspace/
├── main.py              # Главный файл приложения (GUI)
├── commands_db.py       # База данных команд и описаний
├── installer.py         # Модуль установщика ProxSpace
├── pm3_core.py          # Ядро связи с устройством
├── run_app.bat          # Скрипт запуска для Windows
└── README.md            # Этот файл
```

## Требования

- Windows 10/11
- Python 3.10 или выше
- Интернет (для первой загрузки ProxSpace)

## Установка и запуск

### Быстрый старт

1. Установите Python 3.10+ с [python.org](https://python.org) (обязательно отметьте "Add to PATH")
2. Скачайте файлы проекта в одну папку
3. Запустите `run_app.bat`

Скрипт автоматически:
- Проверит наличие Python
- Установит зависимости (customtkinter)
- Запустит приложение

### Ручной запуск

```bash
pip install customtkinter
python main.py
```

## Использование

### Первый запуск

При первом запуске приложение проверит наличие ProxSpace. Если он не найден:
1. Перейдите во вкладку **СИСТЕМА**
2. Нажмите **Установить ProxSpace**
3. Следуйте инструкциям в логе

### Вкладка ГЛАВНАЯ

- Отображение статуса подключения
- Версии Firmware, Bootrom, Hardware
- Кнопки: Подключить, Отключить, Перезагрузка

### Вкладка ПОИСК И ЧТЕНИЕ

- **Auto-Detect**: Полный цикл поиска LF и HF карт
- **LF (125 kHz)**: Поиск, чтение, декодирование EM410x, HID
- **HF (13.56 MHz)**: Поиск, чтение, Mifare Autopwn

### Вкладка ПАМЯТЬ И КЛЮЧИ

*(В разработке)*
- Hex-редактор дампов
- Управление ключами Mifare
- Работа со слотами эмуляции

### Вкладка ЗАПИСЬ

*(В разработке)*
- Запись на T5577
- Запись на Magic Card
- Клонирование

### Вкладка СНИФФИГ

*(В разработке)*
- Перехват трафика LF/HF
- Сохранение дампов

### Вкладка ЭМУЛЯЦИЯ

*(В разработке)*
- Эмуляция карт из слотов
- Настройка UID

### Вкладка ИНСТРУМЕНТЫ

*(В разработке)*
- Графики сигналов
- Демодуляция (ASK, FSK, PSK)
- Спектральный анализ

### Вкладка СКРИПТЫ

*(В разработке)*
- Список Lua-скриптов
- Запуск с аргументами

### Вкладка СИСТЕМА

- Установка ProxSpace (если не установлен)
- Обновление прошивки (Bootrom + Full Image)
- Настройки путей

## Цветовая схема консоли

| Тип | Префикс | Цвет |
|-----|---------|------|
| Успех | `[+]` | Зеленый |
| Ошибка | `[-]` | Красный |
| Предупреждение | `[!]` | Оранжевый |
| Инфо | `[=]` | Голубой |
| Прогресс | `[123/500]` | Обновляет прогресс-бар |

## Безопасность

Перед выполнением опасных команд (прошивка, запись) появляется модальное окно подтверждения.
