# Proxmark3 Easy GUI - Полнофункциональное приложение для работы с Proxmark3 Iceman

## 📡 Описание

**Proxmark3 Easy GUI** — это современное desktop-приложение с графическим интерфейсом для работы с устройствами Proxmark3 (Easy, RDV4, Iceman) под ОС Windows. Приложение полностью заменяет работу с командной строкой, предоставляя интуитивный интерфейс аналогичный Chameleon Ultra GUI или RVC Web UI.

### ✨ Основные возможности

- **Автоматическая установка ProxSpace** — встроенный мастер установки при первом запуске
- **9 функциональных вкладок** — полный доступ ко всем командам Proxmark3 Iceman
- **Визуализация сигналов** — встроенные графики и спектральный анализ
- **Hex редактор** — просмотр и редактирование дампов памяти
- **Редактор скриптов на нодах** — визуальное создание автоматизаций
- **Умные подсказки** — информация о каждой команде с возможностью выполнения `info`
- **Безопасность** — подтверждения опасных операций, цветовая индикация
- **Мультиязычность** — полный русский интерфейс

## 🚀 Быстрый старт

### Требования

- **ОС**: Windows 10/11 (64-bit)
- **Python**: 3.8 или выше
- **Proxmark3**: Easy, RDV4 или совместимое устройство Iceman

### Установка

#### Вариант 1: Автоматическая установка (рекомендуется)

1. Скачайте репозиторий:
```bash
git clone https://github.com/YOUR_USERNAME/proxmark3_easy_gui.git
cd proxmark3_easy_gui
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите приложение:
```bash
python proxmark3_easy_gui.py
```

При первом запуске автоматически запустится мастер установки ProxSpace.

#### Вариант 2: Ручной запуск через .bat файл

Для Windows создан файл `run_app.bat`:
```batch
@echo off
REM Проверка Python
python --version >nul 2>&1
if errorlevel 1 (
    echo Ошибка: Python не найден! Установите Python 3.8+
    pause
    exit /b 1
)

REM Установка зависимостей
pip install -r requirements.txt --quiet

REM Запуск приложения
python proxmark3_easy_gui.py
pause
```

## 🎯 Интерфейс приложения

### 1. 🏠 ГЛАВНАЯ (Dashboard)
- Индикатор статуса подключения (Подключено/Отключено)
- Отображение версий: Firmware, Bootrom, Hardware
- Кнопки: Connect, Disconnect, Restart
- Быстрый доступ к основным функциям

### 2. 🔍 ПОИСК И ЧТЕНИЕ (Search & Read)
- Объединенный интерфейс для LF (125 kHz) и HF (13.56 MHz)
- Кнопка Auto-detect (полный цикл сканирования)
- Отдельные кнопки: LF Search, HF Search, LF Read, HF Read
- Визуализация: текстовый лог с цветовой подсветкой
- Прогресс-бары в реальном времени
- Встроенный график сигнала после чтения

### 3. 💾 ПАМЯТЬ И КЛЮЧИ (Memory & Keys)
- **Hex редактор** с просмотром и редактированием дампов
- Управление ключами Mifare (загрузка .key, сохранение, брутфорс)
- Работа со слотами устройства
- Drag & Drop файлов .eml, .bin

### 4. ✏️ ЗАПИСЬ (Write & Clone)
- Мастер записи: выбор файла или ввод данных вручную
- Поддержка типов карт: T5577, T5555, Magic UID (Gen1/Gen2)
- Настройки безопасности (блокировка секторов)
- Предупреждения перед опасными операциями

### 5. 📡 СНИФФИНГ (Sniffing)
- Запуск перехвата трафика (LF/HF)
- Живая таблица пакетов: Время | Тип | Данные (RAW)
- Кнопки: Start, Stop, Save Dump
- Анализ данных во вкладке «Инструменты»

### 6. 🎭 ЭМУЛЯЦИЯ (Emulation)
- Выбор дампа из Менеджера Памяти или ввод UID вручную
- Параметры эмуляции (тип карты, UID)
- Кнопки: Start Emulation, Stop
- Визуальный индикатор активной эмуляции

### 7. 🛠 ИНСТРУМЕНТЫ (Tools & Plotter)
- Детальный просмотр сигналов (Zoom, масштабирование, панорамирование)
- Инструменты декодирования (Demodulate: ASK, FSK, PSK)
- Спектральный анализ и частотный спектр
- Встроенная панель (не всплывающее окно)

### 8. 📜 СКРИПТЫ (Scripts & Automation)
- Список Lua-скриптов из папки ProxSpace с поиском и фильтрацией
- Поле ввода аргументов команды
- Консоль вывода результатов
- **Визуальный редактор на нодах** для создания скриптов

### 9. ⚙️ СИСТЕМА (System & Setup)
- Мастер установки ProxSpace (виден только если среда не установлена)
- Прошивка (Firmware Update): обновление Bootrom и Full Image
- Настройки: путь к ProxSpace, COM-порт, тема, язык
- Раздел «О программе» и проверка обновлений GUI

## 🔧 Технические особенности

### Парсинг вывода Proxmark3
Приложение перехватывает stdout/stderr от процесса Proxmark3 client:
- Распознавание спецсимволов `[=]`, `[+]`, `[-]`, `[!]`
- Преобразование прогресс-баров `[xxx/yyy]` в графические элементы
- Цветовая кодировка логов

### Умные кнопки с информацией
- **!** — простая подсказка при наведении
- **!!** — выполнение команды `info <command>` по клику
- Группировка команд в выпадающие списки

### Безопасность
- Модальные окна подтверждения для опасных операций
- Цветовая индикация риска (зеленый/желтый/красный)
- Логирование всех действий

## 📝 Примеры использования

### Поиск и чтение карты
1. Перейдите на вкладку **«ПОИСК И ЧТЕНИЕ»**
2. Нажмите **«Auto-detect»** для полного сканирования
3. Просмотрите результаты в логе с цветовой подсветкой
4. Изучите график сигнала ниже логов

### Работа с Hex редактором
1. Откройте вкладку **«ПАМЯТЬ И КЛЮЧИ»**
2. Загрузите дамп через Drag&Drop или кнопку «Открыть»
3. Редактируйте данные в hex или text виде
4. Сохраните изменения в файл

### Создание скрипта на нодах
1. Перейдите во вкладку **«СКРИПТЫ»**
2. Откройте **«Редактор нод»**
3. Добавьте узлы: «Команда» → «Задержка» → «Условие»
4. Соедините ноды и сохраните скрипт

## 🔨 Разработка

### Добавление новых команд
Все команды определены в `src/commands.py`:

```python
"новая_команда": CommandInfo(
    name="Отображаемое имя",
    command="actual command",
    category=CommandCategory.LF,
    description="Описание команды",
    risk=CommandRisk.SAFE,
    hint="Подсказка при наведении"
)
```

### Сборка в .exe
Для создания standalone приложения используйте PyInstaller:

```bash
pip install pyinstaller
pyinstaller --onefile --windowed --name="Proxmark3 Easy GUI" proxmark3_easy_gui.py
```
