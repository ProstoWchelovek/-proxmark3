# Proxmark3 Easy GUI

Полнофункциональное графическое приложение для работы с Proxmark3 Iceman на Windows.

## 🚀 Возможности

### 9 Вкладок Интерфейса:

1. **ГЛАВНАЯ** - Статус устройства, версии прошивки, быстрое подключение
2. **ПОИСК И ЧТЕНИЕ** - Auto-detect, LF/HF поиск, встроенные графики
3. **ПАМЯТЬ И КЛЮЧИ** - Hex-редактор, управление дампами и ключами Mifare
4. **ЗАПИСЬ** - Клонирование карт (T5555, T5577, Magic UID)
5. **СНИФФИНГ** - Перехват трафика в реальном времени
6. **ЭМУЛЯЦИЯ** - Эмуляция карт по слотам
7. **ИНСТРУМЕНТЫ** - Спектральный анализ, декодирование сигналов
8. **СКРИПТЫ** - Запуск Lua-скриптов с аргументами
9. **СИСТЕМА** - Установка ProxSpace, обновление прошивки, настройки

### Особенности:

- ✅ **Умные кнопки** с иконками информации (!/!!)
- ✅ **Цветной вывод** консоли ([=], [+], [-], [!], [?])
- ✅ **Встроенные графики** (matplotlib)
- ✅ **Предупреждения** для опасных команд
- ✅ **Мастер установки** ProxSpace при первом запуске
- ✅ **Адаптивный интерфейс** на CustomTkinter

## 📋 Требования

- Windows 10/11
- Python 3.8+
- Proxmark3 Easy устройство (опционально для тестирования)

## 🛠 Установка

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

Или запустите `run_app.bat` - зависимости установятся автоматически.

### 2. Установка ProxSpace (при первом запуске)

При первом запуске приложение предложит установить ProxSpace:
- Перейдите на https://github.com/Gator96100/ProxSpace
- Скачайте и установите ProxSpace
- Укажите путь в настройках приложения

## 🚀 Запуск

### Вариант 1: Через BAT-файл (рекомендуется)
```bash
run_app.bat
```

### Вариант 2: Через Python
```bash
python proxmark3_easy_gui.py
```

## 📖 Использование

### Подключение к устройству
1. Откройте вкладку **ГЛАВНАЯ**
2. Нажмите **Подключиться**
3. Проверьте версию устройства кнопкой **Get Version**

### Поиск карт
1. Перейдите во вкладку **ПОИСК И ЧТЕНИЕ**
2. Выберите режим (Auto-detect, LF или HF)
3. Нажмите соответствующую кнопку
4. Следите за выводом в консоли и графиками

### Работа с памятью
1. Откройте вкладку **ПАМЯТЬ И КЛЮЧИ**
2. Загрузите дамп кнопкой **Загрузить дамп**
3. Редактируйте в hex-редакторе
4. Сохраните изменения

### Обновление прошивки
1. Перейдите во вкладку **СИСТЕМА**
2. Подключите устройство
3. Нажмите **Update Bootrom** или **Update Full Image**
4. Следите за прогресс-баром

## ⚠️ Предупреждения

Некоторые команды помечены как опасные (красная иконка !!):
- Запись на карты
- Обновление прошивки
- Атаки на Mifare

Перед выполнением таких команд появится диалог подтверждения.

## 🎨 Цветовая схема вывода

| Префикс | Цвет | Значение |
|---------|------|----------|
| `[=]` | Синий | Информация |
| `[+]` | Зеленый | Успех |
| `[-]` | Красный | Ошибка |
| `[!]` | Оранжевый | Предупреждение |
| `[?]` | Фиолетовый | Подсказка |
| `[#]` | Голубой | Конфигурация |
| `[|]`, `[/]`, `[\]` | Бирюзовый | Прогресс |
